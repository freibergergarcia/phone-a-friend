# Phone a Friend

Get second opinions and code reviews from other coding agents while working in
a local repository. Maintained by Bruno Freiberger, licensed under Apache-2.0.

## Setup

Install Node.js 22.13+ and the relay CLI:

```bash
npm install -g @freibergergarcia/phone-a-friend
phone-a-friend doctor
```

Install and authenticate at least one supported backend: Antigravity, Claude
Code, Codex, Gemini CLI, OpenCode, pi, or an Ollama server. Provider subscriptions,
API charges and local-model requirements are separate. Use a backend different
from the current host where its recursion guard applies.

This package supplies instructions for a local coding host with shell and
repository access. Installing it does not install the CLI or authenticate a
backend. Hosted chat environments without those capabilities cannot run the
relay. Windows requires a compatible shell; it has not received live acceptance
testing for these workflows.

## Use

- `phone-a-friend`: ask another backend for a second opinion or review. For
  example: "Use phone-a-friend to ask Claude for a read-only review of this repo."
- `curiosity-engine`: run a structured question-and-answer exchange. For example:
  "Use curiosity-engine to explore this design with Gemini for three rounds."
- `phone-a-team`: iterate across backends in Claude Code or Codex. Claude uses
  its host orchestration; Codex uses Bash rounds and the host model's synthesis.
  For example: "Use phone-a-team to refine this plan with Gemini and OpenCode."

Claude Code exposes namespaced commands such as
`/phone-a-friend:phone-a-friend`; Codex exposes installed skills through its
skill picker. The PaF CLI is required for the Codex team workflow, PaF-managed
sessions, task history, and relays to the pi backend. Claude's team command has
a limited direct-backend fallback when PaF is missing. The single-relay skill
also has direct-CLI fallbacks for Antigravity, Codex and Gemini.

Keep the default read-only relay policy. Diagnose authentication or connectivity
failures with `doctor` and the backend CLI before changing permissions. Host
sandbox restrictions and provider credentials are separate concerns.

Prompts, supplied context and requested diffs go to the selected backend and its
configured provider. PaF stores local history by default. See [PRIVACY.md](PRIVACY.md)
and [SUPPORT.md](SUPPORT.md). Full usage and backend limitations are in the
[project README](https://github.com/freibergergarcia/phone-a-friend#readme).

This folder is generated by `npm run plugins:sync`; edit canonical sources in
the repository. Directory submission and vendor acceptance are separate from
installing this package.
